# AI Language Translator

## Project Overview

AI Language Translator is a Python-based application that translates text into multiple languages using Google Translation services.

This project was developed as part of the CodeAlpha AI Internship.

## Features

* Automatic source language detection
* Translation into multiple languages
* Web application using Flask
* Desktop application using Tkinter
* User-friendly interface
* Error handling for invalid input

## Technologies Used

* Python
* Flask
* Tkinter
* Deep Translator
* HTML
* CSS

## Installation

1. Clone the repository

git clone https://github.com/Bhuvana26052005/AI-Language-Translator.git

2. Install dependencies

pip install -r requirements.txt

3. Run Flask Application

python app.py

4. Open Browser

http://127.0.0.1:5000
